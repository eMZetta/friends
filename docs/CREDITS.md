# Credits und Lizenzen der Audiodateien

Jede Datei unter `src/assets/audio/` wird hier eingetragen, bevor die App veröffentlicht wird.

| Datei | Quelle | Autor / Erzeugt mit | Lizenz | Datum |
| ----- | ------ | ------------------- | ------ | ----- |
| _noch keine Dateien eingebunden_ | | | | |

## Hinweise

- **Suno:** Erzeugt mit einem bezahlten Abo, das die kommerzielle Nutzung erlaubt. Stufe und Datum des Erzeugens
  hier eintragen, die Lizenz gilt für Stücke, die während des Abos entstanden sind.
- **Pixabay:** Content-Lizenz (frei, auch kommerziell, keine Namensnennung nötig). Die Datei darf nicht als
  eigenständiger Download weiterverteilt werden, in der App eingebettet ist sie erlaubt. Titel, Autor und URL notieren.
- Eine Datei ohne Eintrag hier wird nicht veröffentlicht.
